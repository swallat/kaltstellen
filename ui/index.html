    Triggers

    Within about 5 s after one of these programs starts, this profile is applied automatically; 5 to 10 s after the last one ended, the profile from before comes back. A program name or a full path, one per line. When triggers of two profiles run, the higher priority wins.

    Programs that start later

    A program of this profile that starts after the profile was applied gets the action of its entry without a click (stop, freeze or start as in a switch). Needs the optional background helper (Settings, Background helper); without it nothing changes.

    Suggestions

    What you did by hand after this profile was applied, seen again and again. Only a proposal: nothing changes until you add it.

      General

      Starts the tray when you sign in to Windows. It never applies a profile by itself.

      Applies a profile when one of its trigger programs starts, and goes back when the last one has ended. Off pauses all triggers.

      Compares the running programs when a profile was applied with the ones when you switch next, and proposes entries for what you keep doing by hand. Nothing runs in between; no window titles or command lines are kept. Off records nothing.

      Program defaults

      Used by every program entry that does not say otherwise. Each entry can override them in its own dialog. Stored in config.toml, section [settings].

      For entries that name no action. Starting a program is never a default.
